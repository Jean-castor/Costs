# MyClimate - Aplicação de Previsão do Tempo 🌤️

### 📋 Sobre o Projeto
MyClimate é uma aplicação web desenvolvida em React que fornece informações meteorológicas em tempo real e previsões para os próximos cinco dias. O projeto utiliza a API do OpenWeatherMap para obter dados precisos sobre condições climáticas.

### 🚀 Funcionalidades
Busca de informações meteorológicas por cidade
Exibição de temperatura atual
Previsão do tempo para os próximos 5 dias
Alteração dinâmica do fundo baseado na condição climática
Interface responsiva para dispositivos móveis e desktop
